# Looksy Backend — настройка AI-рекомендаций

Бэкенд на Vercel, который генерирует персональные рекомендации через Claude API.
Приложение шлёт сюда метрики лица → бэкенд спрашивает Claude → возвращает советы.

## Зачем нужен бэкенд (а не вызов напрямую из приложения)

API-ключ Claude нельзя зашивать в APK — его легко вытащить декомпиляцией, и кто угодно
будет тратить твои деньги. Поэтому ключ хранится на сервере (Vercel), а приложение
обращается к серверу, защищённому секретом.

---

## ЧАСТЬ 1. Получить ключ Claude API

1. Зайди на **https://console.anthropic.com**
2. Зарегистрируйся (нужна почта)
3. Привяжи **иностранную карту**: раздел **Billing → Add payment method**
4. Пополни баланс минимум на **$5** (раздел Billing → Add credits)
5. Создай ключ: **API Keys → Create Key**, назови например `looksy`
6. Скопируй ключ вида `sk-ant-api03-...` — он показывается ОДИН раз, сохрани

> Стоимость: модель Haiku 4.5 стоит $1 за млн входных токенов и $5 за млн выходных.
> Один запрос рекомендаций ≈ 1500 токенов ≈ **$0.005**. То есть $5 хватит на ~1000 запросов.

## ЧАСТЬ 2. Залить бэкенд на Vercel

У тебя уже есть аккаунт Vercel. Самый простой путь — через GitHub.

### Шаг 1. Положить код на GitHub

1. Создай новый репозиторий на github.com (например `looksy-backend`), приватный
2. Залей в него СОДЕРЖИМОЕ папки `backend/` (не саму папку, а файлы внутри):
   ```
   api/recommendations.js
   package.json
   vercel.json
   ```
   Проще всего: на странице нового репозитория нажми **uploading an existing file**
   и перетащи туда эти файлы (создав папку `api`).

### Шаг 2. Импортировать в Vercel

1. Зайди на **https://vercel.com/dashboard**
2. **Add New… → Project**
3. Выбери репозиторий `looksy-backend` → **Import**
4. На странице настройки:
   - **Framework Preset:** Other
   - **Root Directory:** оставь как есть (`./`)
   - НЕ нажимай Deploy сразу — сначала добавь переменные окружения (следующий шаг)

### Шаг 3. Добавить переменные окружения

В разделе **Environment Variables** на той же странице добавь ДВЕ переменные:

| Name | Value |
|------|-------|
| `ANTHROPIC_API_KEY` | твой ключ `sk-ant-api03-...` |
| `APP_SECRET` | `looksy_ed30ee50f5cac456b82a4d362620f013` |

> `APP_SECRET` уже прописан в приложении (`AppConfig.kt`). Значения ДОЛЖНЫ совпадать.

Теперь нажми **Deploy**. Через минуту получишь URL вида:
```
https://looksy-backend-xxxx.vercel.app
```

### Шаг 4. Проверить, что работает

В терминале (или через любой REST-клиент):

```bash
curl -X POST https://looksy-backend-xxxx.vercel.app/api/recommendations \
  -H "Content-Type: application/json" \
  -H "X-App-Secret: looksy_ed30ee50f5cac456b82a4d362620f013" \
  -d '{
    "score": 8.2,
    "percentile": 80,
    "symmetry": 85,
    "goldenRatio": 82,
    "thirdsProportion": 78,
    "faceShape": "OVAL",
    "description": "Тест"
  }'
```

Должен вернуться JSON с 4 разделами советов. Если так — бэкенд работает.

## ЧАСТЬ 3. Подключить приложение

В файле `app/src/main/java/com/facekit/app/AppConfig.kt` впиши свой URL:

```kotlin
const val BACKEND_URL = "https://looksy-backend-xxxx.vercel.app"
```

Секрет `APP_SECRET` там уже стоит правильный — не трогай его (или поменяй сразу
в двух местах: тут и в переменных Vercel).

Пересобери приложение. Теперь экран «Как тебе стать 9.5?» будет показывать
НАСТОЯЩИЕ рекомендации от Claude, а не демо-текст.

---

## Как понять, что AI работает, а не демо

В приложении на экране рекомендаций:
- **Демо-режим**: вверху висит жёлтая плашка «Демо-режим. Подключи бэкенд…»
- **Реальный AI**: плашки нет, текст каждый раз разный и более детальный

## Безопасность (что есть и чего нет)

Сейчас настроено:
- ✅ Ключ Claude хранится на сервере, не в APK
- ✅ Проверка `X-App-Secret` — отсекает простые чужие запросы
- ✅ Rate-limit 8 запросов/мин с одного IP — защита от случайного спама

Чего пока НЕТ (для будущего масштабирования):
- Жёсткий rate-limit через Upstash Redis (текущий — в памяти инстанса, сбрасывается)
- Секрет всё же можно вытащить из APK. Это фильтр от случайных людей, не от хакеров.
  Для серьёзной защиты нужна аутентификация пользователей (отдельный большой этап).
